Gemini 채보 시험판

음악 파일이나 유튜브 링크를 넣고 채보 시작을 누르면 Gemini가 피아노·베이스·기타·드럼 악보와 코드를 뽑습니다. 악보는 MIDI·MusicXML·PDF로 받습니다.

쓰기 전에 꼭 읽어 주세요
  • 개인 연습용입니다. 저작권이 있는 곡의 악보를 만들어 나누거나 올리거나 파는 것은 저작권 침해가 될 수 있습니다. 교회에서 함께 쓰려면 정식 악보를 구입하거나 CCLI 같은 사용 허락을 받아 주세요.
  • 가사는 따라 칠 때 위치를 알려 주려고 화면에만 보여 줍니다. 받는 파일(PDF·MIDI·MusicXML)에는 가사가 들어가지 않습니다.
  • AI 채보라 틀린 음이 꽤 있습니다. 귀로 확인하며 고쳐 쓰는 초안으로 써 주세요.
  • 소리와 키는 동역 서버를 거치지 않고 이 브라우저에서 Google Gemini로 바로 갑니다. 동역은 아무것도 저장하지 않습니다. 사용량은 본인 키에 잡힙니다(무료 한도 안에서 쓸 수 있음).
● 키 입력 필요

키가 없으면 Google AI Studio에서 무료로 만들 수 있습니다(구글 로그인 → Create API key). Sermon Insight와 같은 키를 씁니다.

또는

유튜브는 공개 영상만 됩니다. 유튜브로 채보하면 원곡 소리 없이 채보한 소리만 재생됩니다.
