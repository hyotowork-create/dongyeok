# 청빙 게시판 수집 허락 요청문

robots.txt로 수집을 막아 둔 학교·교단과 로그인이 필요한 곳은, 허락 없이 수집하지 않고 사이트에 링크만 걸어 두었습니다. 아래 요청문을 각 기관 홈페이지 담당 부서(전산·홍보·기획정보처 등)에 보내고, 허락을 받으면 다음 순서로 수집을 켭니다.

1. `scraper/sources/`에 수집기를 만듭니다. 장신대는 이미 `puts.mjs`가 준비돼 있습니다.
2. 수집기의 `permission`에 허락 날짜, 담당 부서, 허락 범위를 적습니다.
3. `scraper/link-only.json`에서 그 기관을 뺍니다.

> ※ 회신이 없으면 허락하지 않은 것으로 보고 링크만 유지합니다.

## 요청문(이메일)

**제목**: [동역] ○○대학교 청빙 게시판 공고 제목·링크 안내 허락 요청

안녕하십니까. 부교역자를 위한 비영리 커뮤니티 「동역」(https://hyotowork-create.github.io/dongyeok/)을 운영하는 ○○○입니다.

동역은 여러 신학교와 교단 게시판에 흩어진 교역자 청빙 공고를 한곳에서 찾아볼 수 있게 안내하는 사이트입니다. 귀 기관의 「○○ 게시판」도 안내 목록에 포함하고 싶어 허락을 구합니다. 현재는 귀 기관의 robots.txt 설정을 존중하여 수집하지 않고, 게시판 바로가기 링크만 걸어 두었습니다.

**허락해 주시면 다음과 같이 운영합니다.**
- **가져오는 정보**: 공고 제목, 게시일, 원문 링크. 제목에 들어 있는 교회명·지역·직책도 함께 씁니다.
- **가져오지 않는 정보**: 본문, 첨부파일, 연락처, 작성자 정보. 공고 내용은 반드시 귀 기관 게시판의 원문에서 보도록 연결합니다.
- **빈도**: 하루 3회, 1회에 목록 1쪽(요청 1~2건)만 읽습니다. 같은 사이트에는 3초 이상 간격을 둡니다.
- **수집 프로그램 이름(User-Agent)**: `dongyeok-jobs-bot/1.0 (+https://hyotowork-create.github.io/dongyeok/#pg-guide)`
- **출처 표시**: 공고마다 「○○대학교」 출처를 표시합니다.
- **중단**: 언제든 중단을 요청하시면 즉시 멈추고, 이미 안내한 목록도 지웁니다.

**허락 방법**은 둘 중 편하신 쪽으로 해 주시면 됩니다.
1. 이 메일에 회신으로 허락해 주시기.
2. robots.txt에 아래 두 줄을 추가해 주시기. 추가된 것을 확인하면 그날부터 운영합니다.
   ```
   User-agent: dongyeok-jobs-bot
   Allow: /○○(게시판 경로)/
   ```

비영리로 운영하며 광고나 유료 서비스는 없습니다. 궁금하신 점은 아래 연락처로 문의해 주십시오.
